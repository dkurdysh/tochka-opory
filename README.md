## Использование ИИ в разработке

При создании сайта «Точка опоры» использовался ChatGPT (OpenAI) как инструмент для генерации и доработки кода, адаптации макета под разные экраны и настройки публикации сайта.

Концепция, сюжет, визуальный дизайн и макет в Figma разработаны автором проекта. ChatGPT помог перенести макет в статический сайт на HTML, CSS и JavaScript, настроить мобильную версию, анимации, подключение локальных шрифтов и публикацию через GitHub Pages. Результат дорабатывался по замечаниям автора.

### Основной запрос для разработки

Ниже — краткая версия запроса, использованного при создании сайта:

> Создай адаптивный авторский лонгрид для сайта «Точка опоры» по макету Figma. Сохрани его визуальный стиль: тёмный фактурный фон, крупную типографику, бумажные разрывы, чёрно-белые фотографии и оранжевые рукописные акценты.
>
> Сделай отдельную мобильную раскладку для экрана шириной 390 px. Используй локальные изображения и шрифты из проекта.
>
> Добавь появление элементов при прокрутке, индикатор прогресса чтения, кнопку возврата к началу и переключатель анимации. Подготовь сайт так, чтобы его можно было редактировать в VS Code и публиковать через GitHub Pages.

### Что реализовано

- Статическая страница на HTML, CSS и JavaScript без отдельной сборки.
- Десктопная и мобильная версии.
- Локальные шрифты, включая Gochi Hand Cyrillic.
- Анимации при прокрутке, прогресс чтения, кнопка возврата к началу и переключатель анимации.
- Публикация сайта через GitHub Pages из папки `dist`.

### Роль автора и ИИ

**Автор проекта:** концепция и макет в Figma, структура истории, визуальные решения и проверка результата.

**ChatGPT:** помощь с генерацией и доработкой кода, адаптивной вёрсткой, интерактивными элементами и настройкой публикации.
