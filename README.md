# Анатомия разрыва — Точка опоры

Адаптивный авторский лонгрид Дарины Курдыш. Статический сайт без сборки: `dist/index.html`, `dist/style.css`, `dist/app.js`.

Источник дизайна: Figma, файл `wogPBS9h0So9iI5UfyKD7s`, фрейм `46:18`. Все фотографии, фактура, бумажные края и графические коллажи экспортированы из исходных графических слоёв. Вёрстка содержит живой текст и семантические разделы, а не снимок страницы.

## Поведение

- Адаптивная композиция, отдельная мобильная раскладка до 640 px.
- Последовательное появление элементов при прокрутке, увеличение иллюстрации взрыва, появление зачёркивания.
- Прогресс чтения, возврат к началу, переключатель анимации и поддержка prefers-reduced-motion.
- Шрифты и графика загружаются локально. Основной шрифт Roboto Condensed. Рукописный шрифт — Gochi Hand Cyrillic, подключён локально из WOFF-файла.

## Изменения относительно макета

Удалён пустой белый блок, убраны дубли определения безопасного разговора и заключительной цитаты, исправлены опечатки. У карточки статьи не было hyperlink или prototype reaction в Figma, поэтому ссылка явно подписана «Перейти в Дзен» и ведёт в канал https://dzen.ru/tochka_opory_media. Для точного перехода потребуется URL самой статьи.

## Проверка

Проверены desktop и iframe viewport 390 px в браузере: загрузка графики и шрифтов, отсутствие горизонтального переполнения, мобильный светлый раздел, переключатель анимации. JavaScript проверен `node --check dist/app.js`.

## Локальный запуск

Любой статический HTTP-сервер с корнем `dist/`; установка зависимостей не нужна.

## Мобильная версия 390 px

Мобильные стили выделены в mobile.css и mobile-refinements.css. Контрольный размер 390 × 844 px; страница mobile.html показывает сайт в окне шириной 390 px на десктопе. Уточнены переносы, интервалы, размеры текста и зоны нажатия (44 px), добавлены стрелки между этапами, учтён safe-area.
